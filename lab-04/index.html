What are we doing?

An application programming interface (API) lets one program ask another program to do something.

When you use a chatbot website, the website handles the request for you. In this lab, your Python code will send the request directly: choose a model, provide some text, and inspect the result that comes back. This is how developers add model capabilities to their own programs.

An API key is the pass that tells the service which account should pay for a request. Treat it like a password and do not commit it to GitHub or paste it into a shared document. But do not panic: this is a practice account with course credit capped at $40. It cannot expose your bank account, Yale password, or computer. If you accidentally share the key, replace it and let us know.

This lab is a safe place to experiment. Try small changes, look at the responses, and notice how each request uses a little of the available credit.

This activity is separate from Homework 4. Lab time may also include work in the HW4 starter repository and tiny_rnn.py. The API notebook below does not modify or depend on that repository.
