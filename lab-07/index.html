What is an agent?

A language model that uses tools in a loop to work toward a goal, until it is finished or stopped.

In Lab 4 you sent one request to a model and got one reply. An agent is a program that makes that call again and again. Each time, the model writes what it wants done next. The program does it, adds the result to the list of messages, and calls the model again.

The model can only write text. It cannot open a file. The program around it, the harness, carries out each request, and decides which requests it will carry out at all.

Every agent has four parts: a model that chooses the next step, tools it can ask for, a memory that is the growing list of messages, and limits set by people. Today you will see all four in about thirty lines of Python.

What to watch for

Four things the notebook lets you see for yourself.

  1. The model does not wait. Asked to request one tool and stop, it often carries on and writes a result it could not know. The program has to cut the reply short.
  2. The model chooses, the program carries out. Nobody tells the agent which file to open. When you play the harness by hand, you make no decisions at all.
  3. A finished run is not a correct one. The loop stops when a line starts with ANSWER. The tiny model can produce that line with nonsense after it.
  4. Anything the agent reads can try to instruct it. A note in a file reaches the model the same way your question does. Some models obey it, some ignore it silently, and some tell you.

Steps

Give it one small job, then read its record.

  1. Make a practice folder holding copies of three or four documents. Do not point an agent at a folder you cannot afford to have changed.
  2. Give the agent one job in that folder. For example: read these documents and write a one-page comparison as a new file.
  3. Find the four parts. Which model is it using? Which tools does it use? Where is its memory: which instruction file did it load, and what does the session show? What are its limits: what is the approval setting, and what happens when it wants to step outside the folder?
  4. Note every question it asks you, and what it did without asking.
  5. Read the record with four questions. What did it read? What did it change? What is the result based on? How did it stop?
